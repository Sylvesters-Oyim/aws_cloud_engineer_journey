Build a VPC from Scratch + Firewalls

By the end of today you can Build a two-subnet VPC by hand, launch a server in it, explain security groups vs NACLs, and know when a NAT gateway or VPC endpoint is needed.

1. Two firewalls, two different jobs

Analogy: airport securityA security group is the bouncer at the door of one room (an instance): it checks the guest list, and if you were let in, you're let out without being re-checked (stateful). A NACL is the checkpoint at the corridor entrance (a subnet): it checks every person both ways, entering and leaving (stateless), and can explicitly ban people.
Security groupNetwork ACL (NACL)
LevelInstance / network interfaceSubnet
StateStateful (return traffic auto-allowed)Stateless (must allow both directions)
RulesAllow onlyAllow and Deny, evaluated by rule number
DefaultDeny all inbound, allow all outboundDefault NACL allows everything
Exam focus"Block one malicious IP address" → NACL (only NACLs can deny). "Allow web traffic to my servers" → security group. Security groups can reference other security groups (e.g. DB allows only the web tier's group).

2. Getting private things online: NAT and endpoints

A private database sometimes needs to fetch updates from the internet but must never be reachable from it. A NAT Gateway sits in a public subnet and lets private instances start outbound connections; replies come back, but strangers can't initiate. Analogy: a hotel switchboard. Guests can call out through the front desk, but outsiders can't dial a room directly.

A VPC endpoint goes one better: private access to AWS services (like S3) without leaving AWS's network at all. Gateway endpoints (S3 and DynamoDB) are free. Interface endpoints (PrivateLink) cost per hour.

Cost safetyA NAT Gateway bills per hour (about USD 0.045 in many Regions) plus per GB, even when idle. Check current pricing, and in this course we only create one for a few minutes, then delete it. Also release any Elastic IP afterwards (public IPv4 addresses are billed too).

3. Lab: your own VPC (about 60 minutes)

Goal: VPC 10.0.0.0/16 with a public subnet 10.0.1.0/24 and a private subnet 10.0.2.0/24, a web server in the public one.

  1. Create VPC: VPC → Create VPC → VPC only. Name lab-vpc, CIDR 10.0.0.0/16.
  2. Create 2 subnets in lab-vpc, both in the same AZ for now: public-1 = 10.0.1.0/24, private-1 = 10.0.2.0/24. On public-1 → Actions → Edit subnet settings → enable auto-assign public IPv4.
  3. Internet gateway: create lab-igw, then Actions → Attach to VPC lab-vpc.
  4. Route table: create public-rt in lab-vpc. Add route 0.0.0.0/0 → lab-igw. Under Subnet associations attach public-1. Leave private-1 on the VPC's main route table (local only).
  5. Security group web-sg in lab-vpc: inbound HTTP 80 from anywhere, SSH 22 from My IP only.
  6. Launch an EC2 (Amazon Linux, t2/t3.micro) in lab-vpc → public-1, using web-sg. In Advanced → User data, paste: 
    #!/bin/bash
dnf install -y nginx
echo "<h1>Hello from my own VPC</h1>" > /usr/share/nginx/html/index.html
systemctl enable --now nginx
  7. Open the instance's public IP in a browser (http://…). You should see your page. 🎉
  8. Break it on purpose (this is how you really learn): remove the 0.0.0.0/0 → igw route. Reload: it hangs. Add it back. Then remove port 80 from the security group: hangs again. You now know the two usual culprits.
  9. Optional (5 minutes, costs pennies): create a NAT gateway in public-1 with a new Elastic IP, point a private-rt default route at it, then immediately delete the NAT gateway and release the Elastic IP.
  10. Cleanup, in this order: terminate the instance → delete NAT/EIP if made → detach & delete IGW → delete subnets → delete route tables (non-main) → delete security group → delete VPC. (The VPC's "Delete VPC" wizard can remove most of these for you.)

Troubleshooting checklist (memorise, you will use it forever)

  1. Is the instance in a subnet whose route table points to an IGW?
  2. Does it have a public IP?
  3. Does the security group allow the port from your IP?
  4. Does the NACL allow it in and out?
  5. Is the service actually running on the instance?

5. Quiz

1. Which firewall is stateless?The network ACL.
2. How do you block a single IP address range?NACL deny rule.
3. A private instance must download patches but be unreachable from the internet. Which service?NAT Gateway (in a public subnet).
4. Private S3 access with no internet and no hourly cost?Gateway VPC endpoint for S3.
5. VPC A peers with B, B peers with C. Can A reach C?No. Peering is not transitive; use Transit Gateway.
