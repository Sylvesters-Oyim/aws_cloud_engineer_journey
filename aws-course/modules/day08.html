VPC: Your Private Network in the Cloud

By the end of today you can Explain what a VPC, subnet, route table, internet gateway and security group are, and build a custom VPC with a public subnet that serves a web page from an EC2 instance.

1. First principles: why does a VPC exist?

All customers share AWS's physical network. Without isolation your servers would sit next to strangers' servers. A VPC (Virtual Private Cloud) is a logically isolated network that only you control: you choose the IP range, carve it into pieces, and decide what can talk to what and to the internet.

Analogy: an office building The VPC is your building with a fence around it. Subnets are floors (public lobby floor, private back-office floor). The Internet Gateway is the front door to the street. Route tables are the signs saying "to reach the street, use the front door". Security groups are the guards at each office door checking who may enter. A NAT gateway is a mail room: back-office staff can send letters out and get replies, but strangers can't walk in.

2. The five building blocks

PieceWhat it doesScope

3. CIDR in 60 seconds

10.0.0.0/16: the number after the slash is how many leading bits are fixed. Smaller number = bigger network. /16 → 65,536 addresses, /24 → 256, /28 → 16. Subnets inside the VPC must not overlap. Exam favourite: "/16 is the largest VPC size allowed, /28 the smallest."

4. Lab: build a VPC by hand (~45 min)

Cost safetyVPC, subnet, IGW and route tables are free. A t2/t3.micro instance is within free-plan usage. Do not create a NAT Gateway today: it bills hourly (~USD 0.045/h plus data).
  1. Console → VPC → Create VPC → "VPC only". Name day8-vpc, IPv4 CIDR 10.0.0.0/16.
  2. Subnets → Create subnet: VPC day8-vpc, name public-a, pick an AZ, CIDR 10.0.1.0/24. Create a second one private-a with 10.0.2.0/24 in the same AZ.
  3. Select public-a → Actions → Edit subnet settings → tick Enable auto-assign public IPv4 address.
  4. Internet gateways → Create day8-igw → Actions → Attach to VPC day8-vpc.
  5. Route tables → Create public-rt in day8-vpc. Routes → Edit → add 0.0.0.0/0 target Internet Gateway day8-igw. Subnet associations → attach public-a only.
  6. Security groups → Create web-sg in day8-vpc: inbound HTTP (80) from Anywhere, SSH (22) from My IP.
  7. EC2 → Launch instance: Amazon Linux, t3.micro (free-plan eligible), Network day8-vpc, subnet public-a, security group web-sg. In Advanced → User data paste: 
    #!/bin/bash
dnf install -y nginx
echo "<h1>Hello from my own VPC!</h1>" > /usr/share/nginx/html/index.html
systemctl enable --now nginx
  8. Copy the instance's public IPv4 into your browser (http://…). You should see your heading.
  9. Break it to learn it: remove the 0.0.0.0/0 → IGW route and reload. Page dies. Restore it. You've just proved what makes a subnet public.
  10. Cleanup: terminate the instance → delete web-sg → detach and delete the IGW → delete the subnets → delete the VPC. (Deleting the VPC from the console can remove the dependents for you.)

5. Security group vs Network ACL

Security groupNetwork ACL
LevelInstanceSubnet
StateStateful (replies auto-allowed)Stateless (must allow both directions)
RulesAllow onlyAllow and Deny, evaluated in number order
AnalogySecurity group = bouncer who remembers you went out for a smoke and lets you back in. NACL = a checkpoint at the floor entrance that checks your papers every single time, in both directions.

6. Public, private and NAT: when do you need what?

Web servers that must be reachable → public subnet. Databases and app servers → private subnet. If private instances need to download updates, place a NAT Gateway in a public subnet and route the private subnet's 0.0.0.0/0 to it. We will build this with load balancers in Week 5.

7. Quiz (10 min)

1. What makes a subnet "public"?Its route table has a route to an Internet Gateway (and instances have public IPs).
2. Does a subnet span multiple AZs?No. One subnet = one AZ. A VPC spans all AZs in a Region.
3. Security groups are stateful or stateless?Stateful. NACLs are stateless.
4. Your private database must download patches without being reachable from the internet. Use?NAT Gateway in a public subnet.
5. How many addresses are in a /24, and how many are usable in AWS?256; AWS reserves 5, so 251.
6. Can a security group contain a Deny rule?No. Only NACLs can explicitly deny.
