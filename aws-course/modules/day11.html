2. Encryption in two sentences

At rest = data stored on disk is scrambled (S3, EBS, RDS support this with KMS keys, often one click). In transit = data moving over the network is scrambled (HTTPS/TLS). With KMS, the key never leaves AWS's hardware; you only ask it to encrypt/decrypt and IAM + key policies decide who may ask. This is how a thief who steals the disk gets nothing.

Exam focus"Audit all API calls made in the account" → CloudTrail. "Track resource configuration changes over time / check compliance rules" → Config. "Detect compromised instances/malicious IPs" → GuardDuty. "Block SQL injection" → WAF. "Store a database password with automatic rotation" → Secrets Manager.

3. Lab: KMS and CloudTrail (about 50 minutes)

Part A: be your own detective with CloudTrail

  1. Console → CloudTrail → Event history (on by default, last 90 days, free).
  2. Filter Event name = ConsoleLogin. Find your own login: note time, source IP and whether MFA was used.
  3. Filter CreateBucket or RunInstances. Click an event and read the JSON: userIdentity (who), eventTime (when), sourceIPAddress (from where), requestParameters (what).

Part B: encrypt with your own key

  1. KMS → Customer managed keys → Create key: symmetric, encrypt/decrypt, alias alias/day11-key, you as administrator and user.
  2. In CloudShell: 
    echo "my secret plan" > secret.txt
aws kms encrypt --key-id alias/day11-key --plaintext fileb://secret.txt \
  --query CiphertextBlob --output text | base64 --decode > secret.enc
cat secret.enc            # gibberish: encrypted
aws kms decrypt --ciphertext-blob fileb://secret.enc \
  --query Plaintext --output text | base64 --decode
    The last command prints your plan: KMS knew which key to use from metadata inside the file.
  3. Go back to CloudTrail Event history and filter Encrypt/Decrypt. Your own key usage was logged!
  4. Cleanup: KMS → select key → Key actions → Schedule key deletion (minimum 7 days; a key costs about USD 1/month, prorated). rm secret.*

Optional: look, don't leave on

GuardDuty offers a 30-day free trial. Enable it, read the "sample findings" feature to see what threats look like, then suspend/disable it before the trial ends.
