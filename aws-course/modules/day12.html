Security and Compliance Services

By the end of today you can Match the right AWS security service to a scenario (30% of the Cloud Practitioner exam is security!), encrypt with KMS, and find out "who did what" with CloudTrail.

1. First principles: the four security questions

Almost every AWS security service answers one of four questions. Learn the questions and the service names stick.

Analogy: protecting a shopLocks and keys (IAM, KMS) · Security guard at the door filtering bad customers (WAF, Shield, firewalls) · CCTV cameras recording everything (CloudTrail, Config, CloudWatch) · A security consultant who walks the shop looking for weaknesses and alarms when a thief appears (Inspector, GuardDuty, Macie, Trusted Advisor).

Exam tipConfusing pair: CloudTrail = "who made this API call?", CloudWatch = "how is my system performing?", Config = "how did this resource's settings change?".

3. Encryption in 3 sentences

At rest = data stored on disk is scrambled (S3, EBS, RDS support this with one tick, using KMS keys). In transit = data moving over the network is scrambled (HTTPS/TLS). Envelope encryption = a master key in KMS protects small data keys, and data keys protect your data, so the master key never leaves KMS.

4. Lab: who deleted my file? (60 min)

  1. CloudTrail → Event history (free, last 90 days of management events). Filter Event name = ConsoleLogin. Find your own sign-in. Note source IP and whether MFA was used.
  2. Create an S3 bucket day12-<yourname>-<random> with SSE-KMS default encryption (choose the AWS managed key aws/s3; free).
  3. Upload a text file, then delete the bucket's file. In CloudTrail event history filter Event source = s3.amazonaws.com (data events are not logged by default; bucket-level calls like CreateBucket are). Wait up to 15 minutes if events don't show.
  4. KMS → AWS managed keys: open aws/s3 and read its key policy. Who can use it?
  5. Trusted Advisor / Security Hub overview: skim what it flags on your account (MFA on root? public buckets?).
  6. Artifact: open it and find the SOC 2 or ISO 27001 report list (you don't need to download).
  7. Optional: GuardDuty has a 30-day trial; enable only if you will check it and disable after.
  8. Cleanup: delete the bucket. CloudTrail event history costs nothing; don't create extra trails that write to S3 unless you plan to delete them.

5. Quiz: match the service

1. Your site is hit by a flood of fake traffic.AWS Shield (Standard is automatic and free) plus CloudFront/WAF rate limiting.
2. Block SQL-injection attempts on a web app.AWS WAF.
3. Who terminated that EC2 instance last night?CloudTrail.
4. Find credit-card numbers accidentally stored in S3.Amazon Macie.
5. Detect a compromised instance mining crypto.Amazon GuardDuty.
6. Rotate a database password automatically.AWS Secrets Manager.
7. An auditor wants AWS's ISO certificates.AWS Artifact.
8. Is HTTPS encryption "at rest" or "in transit"?In transit.
