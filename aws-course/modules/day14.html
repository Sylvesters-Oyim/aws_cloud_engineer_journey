1. Mini-project: "ShopFast" network design

A client wants a small online shop. Requirements: public website, database nobody on the internet can reach, HTTPS, fast for users in Africa and Europe, alerts if the server struggles, and an audit trail. Design it on paper first, then build the core in AWS.

Build (1.5–2 h)

Cost safetyNo NAT gateway, no RDS yet. Use two t3.micro EC2 instances (a stand-in "DB" is fine: just run python3 -m http.server 3306 or install MariaDB) and delete everything afterwards.
  1. Build the VPC, a public and a private subnet, IGW, and two route tables (quick now, you did it on Day 8-9).
  2. Web instance in public subnet with nginx, security group ports 80 (anywhere) and SSH (my IP only).
  3. "DB" instance in the private subnet. Security group inbound 3306 only from the web SG.
  4. From the web instance prove reachability: nc -zv PRIVATE_IP 3306 succeeds. From your laptop it can't even be attempted (no public IP).
  5. Put CloudFront in front of the web instance (origin = its public DNS name, HTTP only to origin for this lab). Test x-cache headers.
  6. Add the CPU alarm from Day 13.
  7. Export your diagram (draw.io, or hand-draw and photo) to evidence/day14-architecture.png.
  8. Cleanup everything. Verify Billing → Bills shows nothing running.

2. Week 2 mixed quiz (15 min, no notes)

1. How many IPs does AWS reserve in each subnet?5.
2. A DB subnet must not be reachable from the internet. What's different about its route table?No route to an internet gateway.
3. Private instances need outbound internet only. Which service?NAT gateway (in a public subnet).
4. SG or NACL: allow rules only and stateful?Security group.
5. Which Route 53 policy sends a % of traffic to each endpoint?Weighted.
6. Apex domain pointing to CloudFront?Alias record.
7. How do you let only CloudFront read a private bucket?OAC + bucket policy.
8. Which service tells you who deleted a resource?CloudTrail.
9. Which finds PII in S3?Macie.
10. Where is a user's database password best stored?Secrets Manager (retrieved with an IAM role).
11. A VPC endpoint to S3 that is free?Gateway endpoint.
12. Shield Standard cost?Free, always on.
