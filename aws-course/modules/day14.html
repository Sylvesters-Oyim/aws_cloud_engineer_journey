Week 2 Review and Mock Exam

By the end of today you can Score yourself on a 40-question Cloud Practitioner-style mock, find your weak domains, and have a booked exam date and a 2-week plan.

1. Where you stand

You have now met almost every service behind the CLF-C02 exam: cloud concepts, IAM, EC2, S3, EBS, VPC, Route 53, CloudFront, KMS, CloudTrail, CloudWatch, billing tools and support plans. The exam is mostly recognition: "which service solves this?". Your hands-on labs give you the edge.

2. Mock exam: 40 questions (45 minutes, no notes)

RulesWrite your answers on paper first, then open each answer. Count correct ones. 28/40 (70%) is a safe pass line; aim for 34+.
1. Which responsibility belongs to AWS under the shared responsibility model?Security of the cloud: physical data centers, hardware, hypervisor, managed-service infrastructure.
2. A company wants to move from CapEx to OpEx. Which cloud benefit is this?Pay-as-you-go pricing (trade fixed expense for variable expense).
3. Which design principle improves resilience against a data center failure?Deploy across multiple Availability Zones.
4. Which IAM feature gives an EC2 instance permissions without storing keys?IAM role (instance profile).
5. Best protection for the root user?Strong password + MFA, no access keys, don't use for daily work.
6. A subnet's route table has 0.0.0.0/0 → igw. What is the subnet?Public subnet.
7. Which firewall can explicitly deny an IP?Network ACL.
8. Private instances need outbound internet only. Which service?NAT Gateway.
9. Which service gives low-latency global delivery of static content?CloudFront.
10. Which Route 53 policy sends users to the lowest-latency Region?Latency-based routing.
11. Which S3 storage class is cheapest for rarely accessed archival data with hours-long retrieval?S3 Glacier Flexible Retrieval / Deep Archive.
12. Which EC2 purchase option suits a fault-tolerant batch job at the lowest cost?Spot Instances.
13. Which tool forecasts and alerts on spend?AWS Budgets.
14. Which service audits API calls?CloudTrail.
15. Which service detects threats such as crypto-mining instances?GuardDuty.
16. Which service blocks SQL injection on an ALB or CloudFront?AWS WAF.
17. Where do you get AWS compliance reports (SOC, ISO)?AWS Artifact.
18. Which service stores and rotates database credentials?Secrets Manager.
19. Which service is a managed key store for encryption keys?AWS KMS.
20. Which metric needs the CloudWatch agent on EC2?Memory utilisation (and disk space).
21. Which service sends email/SMS notifications to subscribers?SNS.
22. Which Well-Architected pillar covers 'recover from failure automatically'?Reliability.
23. Which service gives automated advice on cost optimisation and security gaps?Trusted Advisor.
24. Which pricing option gives up to ~72% off for 1 or 3 year commitments with flexibility across instance families?Compute Savings Plans.
25. Which service lets one company manage many accounts with consolidated billing?AWS Organizations.
26. Block-level storage that lives in a single AZ?EBS.
27. Which service gives a managed relational database with automated backups?Amazon RDS.
28. Which service runs code without servers, billed per execution?AWS Lambda.
29. Which Well-Architected pillar is about reducing environmental impact?Sustainability.
30. Dedicated private network connection from office to AWS?AWS Direct Connect.
31. What do you call a copy of an EBS volume at a point in time?Snapshot.
32. Which AWS service provides virtual servers?Amazon EC2.
33. The cheapest way to learn without a surprise bill?Set a Budget and billing alerts, use cleanup steps, delete unused resources.
34. Which tool estimates the cost of an architecture before building?AWS Pricing Calculator.
35. Which support plans include 24/7 access to AWS experts (exam guides may use older names too)?Business Support+ / Enterprise / Unified Operations (older: Business and Enterprise).
36. S3 data is lost if the AZ fails? True or false?False: S3 stores data redundantly across multiple AZs (except One Zone classes).
37. Which service provides DDoS protection at no extra cost on all accounts?Shield Standard.
38. Which EC2 option is a physical server dedicated to you for licensing needs?Dedicated Host.
39. What does 'elasticity' mean?Resources scale out and in automatically with demand.
40. Which CloudFront feature keeps an S3 origin private?Origin Access Control (OAC).

3. Fix weak spots (the highest-value hour of the week)

  1. For each missed question write a one-line rule in your notes: "Cheapest interruptible compute = Spot".
  2. Group misses by domain. Reread that Day's concept section, not the whole module.
  3. Teach it back: explain 3 missed topics out loud as if to a friend (Feynman technique).
  4. Re-take only the missed questions tomorrow (spaced repetition).

4. Book the exam

Go to aws.amazon.com/certification → Cloud Practitioner (CLF-C02) → schedule with Pearson VUE (test centre or online proctored). Pick a date about 3 weeks away. A booked date turns "someday" into a deadline. First-time AWS candidates often get an exam voucher or practice-exam benefits, so check your AWS Certification account. Look for the free AWS Skill Builder Official Practice Question Set and Exam Prep plan.
