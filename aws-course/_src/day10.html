By the end of today you can Trace what happens when you type a web address, read DNS records with dig, and explain Route 53 record types and routing policies. Optionally, point a real domain at your server.

1. First principles: computers talk in numbers, people in names

Servers are found by IP address (203.0.113.10). Humans remember names (example.com). DNS (Domain Name System) is the global phone book translating one to the other. Amazon Route 53 is AWS's DNS service (53 is the DNS port number).

Analogy: asking for directions Your laptop asks a resolver (a helpful local who knows shortcuts: "where is shop.example.com?"). If it doesn't know, it asks the root ("who handles .com?"), then the .com registry ("who handles example.com?"), then the domain's name servers (the shop's own receptionist: "it's at 203.0.113.10"). The answer is remembered for a while (the TTL) so the next ask is instant.

Routing policies (Route 53's superpower)

PolicyBehaviourReal-life use
SimpleOne answerA single website
WeightedSplit traffic by % (90/10)Canary release of a new version
LatencySend user to the lowest-latency RegionGlobal app in 2+ Regions
FailoverPrimary, switch to secondary if health check failsDisaster recovery
GeolocationBy user's country/continentLegal or language rules
GeoproximityBy distance, with adjustable biasShift load toward a Region
MultivalueUp to 8 healthy answersCheap client-side balancing

3. Lab part A: be a DNS detective (free, 20 min)

dig aws.amazon.com            # the answer + TTL
dig +short NS amazon.com      # who is in charge of the domain
dig +trace example.com        # watch root → .com → name server steps
dig MX gmail.com +short       # mail records
dig www.github.com            # spot the CNAME in the answer

If dig is missing: sudo apt install dnsutils (Debian/Ubuntu) or sudo dnf install bind-utils. Write down: what TTL did you see? Why would a short TTL matter before you migrate a website?

4. Lab part B: your own domain (optional, ~USD 3–15/yr)

Cost safetyA hosted zone costs USD 0.50/month (not free-tier). Domain registration is a yearly fee (.click and similar are among the cheapest). Skip Part B if you'd rather not pay. You'll still pass the exam. Delete the hosted zone after the lab to stop the monthly charge.
  1. Route 53 → Registered domains → Register a cheap domain (or use one you own and point its nameservers to Route 53's NS records).
  2. Open the hosted zone. Launch your Day 8 web instance again (public subnet, port 80 open) and note its public IP.
  3. Create record: name www, type A, value = the instance IP, TTL 60. Visit http://www.yourdomain.
  4. Add a second record blue weighted 50 and a third green weighted 50 pointing to different pages if you like, and refresh a few times to watch the split.
  5. Cleanup: terminate the instance; delete the records and hosted zone; turn off auto-renew if you don't want to keep the domain.

5. Exam notes

Remember
  • Route 53 does three jobs: domain registration, DNS, health checks.
  • Apex domain to a CloudFront/ALB → use an Alias record, not CNAME.
  • Failover = DR. Latency = performance. Geolocation = compliance/localisation. Weighted = gradual rollout.
  • Route 53 is a global service with a 100% availability SLA.

6. Quiz

Q1. You want example.com (no www) to point to a CloudFront distribution. Record type?Alias (A) record. A CNAME is not allowed at the apex.
Q2. Send 10% of users to a new version first. Policy?Weighted routing.
Q3. Users in Germany must see the EU site. Policy?Geolocation routing.
Q4. Automatically move traffic to a standby site if the primary dies?Failover routing with a Route 53 health check.
