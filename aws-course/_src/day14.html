1. The billing & support cheat-sheet (CLF-C02 Domain 4)

TopicWhat to know
Pricing principlesPay as you go · pay less when you reserve · pay less per unit when you use more (tiered pricing) · data IN is generally free, data OUT to the internet costs
Cost toolsPricing Calculator (estimate before), Cost Explorer (analyse past spend), Budgets (alerts), Cost & Usage Report (most detailed), Cost Allocation Tags
AWS OrganizationsMultiple accounts, consolidated billing, volume discounts, Service Control Policies (SCPs)
Support plansBasic (free: docs, Trusted Advisor core checks) · Developer (business-hours email) · Business (24/7, full Trusted Advisor, production) · Enterprise On-Ramp / Enterprise (TAM, mission critical). Only higher plans give a Technical Account Manager
Migration & otherCloud Adoption Framework, Snow family (physical data transfer), Migration Hub, Marketplace
Analogy: phone data plansPay-as-you-go (On-Demand), a contract with discounts (Savings Plans/RIs), and a family plan sharing allowances across members (consolidated billing).

2. 25-question mini-exam (target: 40 min, no notes)

Write your answers on paper first, then open the answers. 18/25 (72%) or more is on track for the real pass mark of 70%.

1. A company wants to avoid upfront hardware purchases. Which cloud benefit?Trade capital expense for variable expense.
2. Which is the customer's responsibility under Shared Responsibility?Configuring IAM and security groups (and patching the guest OS on EC2).
3. What is an Availability Zone?One or more discrete data centres with independent power/networking inside a Region.
4. Which feature provides temporary credentials to an application on EC2?IAM role.
5. Which service stores unlimited objects with 11 nines durability?Amazon S3.
6. Which S3 class suits unknown access patterns?S3 Intelligent-Tiering.
7. Lowest-cost, rarely accessed archive with hours retrieval?S3 Glacier Deep Archive / Glacier Flexible Retrieval.
8. A subnet with a route to an internet gateway is called?Public subnet.
9. Which is stateless and supports deny rules?Network ACL.
10. Private instances need outbound internet only. Use?NAT gateway.
11. DNS service in AWS?Route 53.
12. Reduce latency for global users of a website?CloudFront.
13. Which service records API calls made in your account?CloudTrail.
14. Which service monitors performance metrics and alarms?CloudWatch.
15. Managed DDoS protection that is free for all customers?Shield Standard.
16. Block SQL injection on a web app?AWS WAF.
17. Create/manage encryption keys?AWS KMS.
18. Find PII in S3?Amazon Macie.
19. Estimate the cost of a planned architecture?AWS Pricing Calculator.
20. Get alerted when spend passes USD 10?AWS Budgets.
21. Which support plan first includes a Technical Account Manager?Enterprise (On-Ramp offers a pool of TAMs).
22. Consolidated billing belongs to which service?AWS Organizations.
23. Cheapest option for fault-tolerant batch jobs?Spot Instances.
24. Which EC2 storage disappears when the instance stops?Instance store.
25. Which Well-Architected pillar covers recovering from failure?Reliability.
