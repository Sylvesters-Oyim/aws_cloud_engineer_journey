3. Mock exam (20 questions, 30 minutes, no notes)

1. How many usable IPs in a /28 subnet?11 (16 − 5).
2. Which resource makes a subnet public?A route to an internet gateway (plus public IP).
3. Which firewall can explicitly deny traffic?Network ACL.
4. A private instance must download updates. Solution?NAT gateway in public subnet.
5. Cheapest way for private instances to reach S3?Gateway endpoint.
6. Two VPCs need to talk privately. Simplest option?VPC peering (use Transit Gateway for many VPCs).
7. Encrypted private line from office to AWS over the internet?Site-to-Site VPN.
8. Dedicated fibre from office to AWS?Direct Connect.
9. Route 53 policy for disaster recovery?Failover.
10. Route 53 policy for lowest delay across Regions?Latency.
11. Which record is used for the zone apex pointing to an ALB?Alias A record.
12. What does CloudFront cache at?Edge locations.
13. Keep an S3 origin private behind CloudFront?Origin Access Control.
14. DDoS protection included free for all customers?Shield Standard.
15. Filter malicious HTTP requests like SQL injection?WAF.
16. Record of every API call in your account?CloudTrail.
17. Continuous threat detection from logs?GuardDuty.
18. Who is responsible for patching the guest OS on EC2?The customer.
19. Where do you download AWS compliance reports?AWS Artifact.
20. A security group allows inbound 80. Do you also add an outbound rule for the reply?No, security groups are stateful.

Scoring: 16+ = move on. 12–15 = redo Days 8, 10 or 12 labs quickly. Below 12 = repeat Day 9's build from memory.
