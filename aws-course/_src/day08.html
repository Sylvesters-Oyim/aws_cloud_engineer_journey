By the end of today you can Explain what a VPC, subnet, route table and internet gateway are, read a CIDR block like 10.0.0.0/16, and build your own network from scratch with a web server inside it.

1. First principles: why do we need a "VPC"?

In Week 1 you launched EC2 into a ready-made network without thinking about it. That was the default VPC. Real systems need control: which machines can the internet see, which are hidden, and who can talk to whom? A VPC (Virtual Private Cloud) is your own isolated slice of the AWS network where you decide all of that.

Analogy: a gated estate The VPC is the whole estate with a perimeter wall. Subnets are the streets inside it. The internet gateway is the main gate to the public road. Route tables are the signposts at each street ("to leave the estate, go to the gate"). A street with no signpost to the gate is a private street: residents can talk to each other but nobody from outside can drive in.

2. The five building blocks

PieceWhat it isKey facts
VPCYour private network, in one RegionYou pick an IP range (CIDR), e.g. 10.0.0.0/16 (65,536 addresses)
SubnetA smaller range carved out of the VPCLives in one AZ. AWS reserves 5 addresses in each
Route tableRules: "traffic for X goes to Y"Each subnet is associated with exactly one
Internet Gateway (IGW)Door between the VPC and the internetAttached to a VPC; free
Public IP / Elastic IPThe address the internet seesInstance also needs a route to the IGW
The rule that defines "public subnet"A subnet is public if its route table has 0.0.0.0/0 → igw-xxxx. That's the whole definition. No such route = private subnet.

CIDR in 60 seconds

An IP like 10.0.1.0/24 has 32 bits. The number after the slash says how many bits are fixed (the network part). The rest are free for hosts. So /24 = 8 free bits = 28 = 256 addresses; /16 = 16 free bits = 65,536. Smaller number after the slash = bigger network. Quick check: /28 is the smallest subnet AWS allows (16 addresses, 11 usable).

3. Lab: build a VPC by hand (60 min)

Cost safetyVPCs, subnets, route tables and IGWs are free. The one EC2 instance is the only cost. Terminate it at the end.
  1. Console → VPC → Create VPC → "VPC only". Name day8-vpc, IPv4 CIDR 10.0.0.0/16. Create.
  2. Subnets → Create subnet: VPC = day8-vpc. Create day8-public-a (AZ a, 10.0.1.0/24) and day8-private-b (AZ b, 10.0.2.0/24).
  3. Internet gateways → Create day8-igw → Actions → Attach to VPC → day8-vpc.
  4. Route tables → Create day8-public-rt in day8-vpc. Open it → Routes → Edit → Add 0.0.0.0/0 → Internet Gateway → day8-igw. Then Subnet associations → attach day8-public-a.
  5. Select day8-public-a → Actions → Edit subnet settings → enable auto-assign public IPv4.
  6. Launch an EC2 (Amazon Linux 2023, free-tier type) with Network = day8-vpc, Subnet = day8-public-a, new security group (HTTP from anywhere, SSH from My IP) and the same user data as Day 5.
  7. Open its public IP in your browser. Your page is live in a network you built.
  8. Break it to learn it: delete the 0.0.0.0/0 route in the route table and reload. It stops working even though the security group is fine. Routing and security are separate layers. Add the route back.
  9. Cleanup: terminate the instance. Leave the VPC (free) for Day 9.

4. Exam notes

Remember
  • A VPC spans all AZs in one Region; a subnet lives in one AZ.
  • The default VPC is 172.31.0.0/16 with a public subnet in every AZ.
  • Public subnet = route to an IGW. Private = no such route.
  • CIDR sizes allowed for VPCs: /16 (largest) to /28 (smallest).
  • Every route table has an unremovable local route so resources in a VPC can reach each other.

5. Quiz

Q1. How many addresses does a /24 give, and how many can you actually use in AWS?256; 251 (AWS reserves 5).
Q2. Your instance has a public IP and open port 80 but the page times out. What do you check next?The subnet's route table: is there a 0.0.0.0/0 route to an internet gateway?
Q3. Can one subnet span two Availability Zones?No. A subnet is in exactly one AZ.
Q4. What makes a subnet "public"?A route to an Internet Gateway in its route table.
