By the end of today you can Build a VPC from scratch with public and private subnets, explain what makes a subnet "public", and say why a NAT gateway exists. This is the single most tested topic on the Solutions Architect exam, so we start it now.

1. First principles: why does a network need to be "yours"?

Thousands of customers run on the same AWS hardware. Without a boundary, your database could be reachable by a stranger's server. A VPC (Virtual Private Cloud) is a logically isolated network that only you control: you pick the IP range, split it into pieces, and decide what can talk to what and to the internet.

Analogy: an office building you rentThe VPC is the building. Subnets are floors (each floor sits in one AZ's wing). The Internet Gateway is the front door to the street. The route table is the signage telling people which way to go. A NAT gateway is the mailroom: staff in the back office can send letters out and receive replies, but strangers can't walk in. Security groups are the guard on each room's door.

2. The building blocks

PieceWhat it doesRemember
CIDR blockThe VPC's IP range, e.g. 10.0.0.0/16 (65,536 addresses)Bigger number after / = smaller network. /16 to /28 allowed.
SubnetA slice of the VPC in one AZ, e.g. 10.0.1.0/24AWS reserves 5 addresses per subnet.
Route tableRules: "traffic for X goes to Y"Every subnet is associated with one.
Internet Gateway (IGW)Door between VPC and the internetOne per VPC, free, highly available.
NAT GatewayLets private instances reach out (updates) but blocks inboundLives in a public subnet. Costs ~USD 0.045/hour plus data. Delete after labs!
Security GroupFirewall on the instance. Stateful, allow rules only.Reply traffic is auto-allowed.
Network ACLFirewall on the subnet. Stateless, allow + deny, numbered rules.You must allow return traffic yourself.
The one sentence that unlocks VPCA subnet is public if and only if its route table has a route 0.0.0.0/0 → Internet Gateway. Nothing else makes it public. A subnet with no such route is private.

3. Security groups vs NACLs (guaranteed exam question)

Security GroupNetwork ACL
LevelInstance (ENI)Subnet
StateStatefulStateless
RulesAllow onlyAllow and Deny
DefaultAll inbound denied, all outbound allowedDefault NACL allows everything

Analogy: the security group is the bouncer who remembers you went out for a smoke and lets you back in. The NACL is a checkpoint at the building gate that checks your ticket every single time, in both directions.

4. Lab (60 min): build it yourself, the manual way

Cost safetySteps 1 to 6 are free. The NAT gateway in step 7 costs money per hour, so do it last, take your screenshot, and delete it straight away.
  1. Console → VPC → Create VPC → "VPC only". Name lab-vpc, IPv4 CIDR 10.0.0.0/16.
  2. Subnets → Create subnet in lab-vpc: public-a = 10.0.1.0/24 in AZ a, and private-a = 10.0.2.0/24 in the same AZ.
  3. Internet gateways → Create lab-igw, then Actions → Attach to VPC lab-vpc.
  4. Route tables → Create public-rt in lab-vpc. Edit routes: add 0.0.0.0/0 → lab-igw. Subnet associations: attach public-a.
    Now ask yourself: which subnet is public, and why? (Look at the one sentence in section 2.)
  5. On public-a: Edit subnet settings → enable auto-assign public IPv4.
  6. Launch a t2.micro/t3.micro Amazon Linux instance in public-a, with a new security group allowing SSH (22) from My IP only. Connect with EC2 Instance Connect and run curl -s https://checkip.amazonaws.com. It works, so you have internet.
  7. Launch a second instance in private-a with no public IP (security group: allow SSH from the web server's security group). From the web server, SSH to its private IP. From your laptop, notice you can't reach it directly. That is isolation.
  8. NAT (short, then delete): NAT gateways → Create in public-a with a new Elastic IP. Create private-rt with 0.0.0.0/0 → NAT, associate private-a. Screenshot the route table. Then delete the NAT gateway, release the Elastic IP.
  9. Cleanup: terminate both instances, delete NAT (if not already), release Elastic IP, detach and delete the IGW, delete subnets, route tables, and finally the VPC. (Deleting the VPC last is the order AWS enforces anyway.)

5. Exam-style quiz (10 min)

1. What makes a subnet public?A route to an Internet Gateway (0.0.0.0/0 → igw-...).
2. Instances in a private subnet need to download OS patches. Which service?A NAT Gateway placed in a public subnet.
3. Is a security group stateful or stateless?Stateful. Return traffic is automatically allowed.
4. You must explicitly block one malicious IP address. Which tool?A Network ACL deny rule (security groups can't deny).
5. How many addresses does AWS reserve in each subnet?Five.
6. Can one subnet span two Availability Zones?No. A subnet lives in exactly one AZ.
7. Which CIDR holds more addresses: /16 or /24?/16 (65,536 vs 256).
8. Which is the shared responsibility split for a VPC firewall config?The customer configures security groups, NACLs and routes; AWS runs the underlying network.
